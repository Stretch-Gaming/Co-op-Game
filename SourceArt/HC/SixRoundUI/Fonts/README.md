# Six-round UI fonts

Averia Serif Libre Regular and Bold, by Dan Sayers (2011), from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/averiaseriflibre). Downloaded October 10, 2026 as unmodified TTFs. `OFL.txt` contains the copyright notice, reserved font names and SIL Open Font License 1.1. That license permits bundling and redistribution with the game when the notice and license accompany the fonts.

The editor importer creates FontFace assets and runtime composite Font assets under `Content/Shared/UI/Fonts/`, under LFS locks. It does not alter the source fonts. Source/derived hashes and editor diagnostics belong in the integration evidence for [#93](https://github.com/Stretch-Gaming/Co-op-Game/issues/93). Visual and split-screen acceptance remain required after import.
